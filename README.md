# DryONut – Flask e-commerce demo
    pip install -r requirements.txt
    python app.py        # http://localhost:5000
Pages: Home, Shop, Product, Reviews, About, Contact, Bag, Checkout, Order success.
Payments: demo gateway by default. For Razorpay test mode, set RAZORPAY_KEY_ID / RAZORPAY_KEY_SECRET (see .env.example) before running.
